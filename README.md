## 📁 Playlist Format

The playlist follows standard M3U format:

```m3u
#EXTM3U

#EXTINF:-1 tvg-id="channel-id" tvg-name="Channel Name" tvg-logo="logo-url" group-title="Category",Channel Name
https://example.com/live/channel.m3u8
```
